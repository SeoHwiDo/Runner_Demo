## 4. 현재 작업

- 카드: `NEXT-01`
- 목표: 기본형 맵 타일을 풀링해 끊김 없이 지속 이동하는 흐름을 구현한다.
- 선행 구현:
  - 기본형 맵 타일 액터
  - 맵 타일 머티리얼
  - 플레이어 이동용 발판·사이드 콜리전
  - `TileManager`의 초기 타일 풀 생성과 순차 배치
- 완료 조건:
  - Unreal Engine 5.7.4 Blueprint-only로 구현한다.
  - 맵 타일을 무제한 Spawn/Destroy하지 않고 재사용한다.
  - 관련 Blueprint 컴파일 오류와 새 경고가 없다.
  - PIE에서 타일 연결과 지속 이동의 정상·경계 경로를 확인한다.
- 영향 예상: `Content/Runner/Blueprints/Core`, `Content/Runner/Maps`, 맵 타일 Blueprint와 관련 데이터
- 현재 확인: 초기 타일 생성까지 구현했다. UE 5.7.4 `CompileAllBlueprints` 결과는 Blueprint 오류 0개·경고 0개·로드 실패 0개이며, 명령 종료 코드는 샌드박스 DDC/Zen 쓰기 제한으로 1이었다. PIE 재검증은 아직 수행하지 않았다.
- 다음 행동: 맵 범위 콜리전에서 완전히 벗어난 타일을 감지해 앞쪽 SpawnPoint로 재배치하고, 경계의 틈·중첩을 PIE에서 확인한다.
