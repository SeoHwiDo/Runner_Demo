현재 작업: **M1-01/SYS-03 — 플레이어 레일 이동/카메라**

## 1. 제품 한 문장

플레이어가 좌우로 이동하며 자동 사격하고, 전투 중 선택한 화살·비행검·동료 강화로 빌드를 만든 뒤 보스를 넘어 최고 점수에 도전하는 짧은 3D 자동 러너다.

## 2. 기준 콘텐츠와 구현 범위

원작에서 확인한 기준은 자동 전진/자동 사격, 좌우 이동, 선택형 파워업, 펫과 비행검, 보스 클리어 또는 이후 최고 점수 도전, 골드 기반 영구 강화다. 원작에는 빨강/파랑/보라 계열 무기 빌드, 개/용 동료, 점수·상점·런 기록·36개 업적이 존재한다.

| 원작 기준 | 9월 3일 목표 | 우선순위 |
|---|---|---|
| 좌우 이동 + 자동 전진/사격 | 완전 구현 | Must |
| 도로 2열 강화 + 보스 3개 보상과 유료 재추첨 | 완전 구현 | Must |
| 화살/비행검/동료 빌드 | 2개 완전 구현, 1개 기본 구현 | Must/Should |
| 일반 적과 보스 | 일반 적 3종, 중간/최종 보스 2종 | Must |
| 보스 클리어 후 최고 점수 | 클리어 선택 + 무한 스케일링 | Must |
| 골드와 영구 상점 | 체력/화살 피해/발사 수/비행검 기본 강화 | Must |
| 런 기록 | 최고 점수와 최근 결과 요약 | Should |
| 36개 업적/전체 콘텐츠 | 이번 마감에서 제외 | Won't |

Trello에는 마감 커밋 범위와 별개로 원작 전체 구현 명세를 보존한다. 현재 상세 백로그는 시스템 범위 29개(전용 `[SYS]` 카드 28개와 `M1-01`에 병합된 `SYS-03` 1개)와 `[CNT]` 콘텐츠 24개이며, 문서로 확정되지 않은 원작 수치는 `[CNT-00] 원작 플레이 캡처와 콘텐츠 대조표`를 통과한 뒤 확정한다.
